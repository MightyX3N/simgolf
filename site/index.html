What it is

The rules and numbers come from OpenSGolf, a faithful open source reimplementation of SimGolf. Everything around them is built for Garry's Mod.

Plays like SimGolf

Build holes, paint terrain, place buildings and hire staff. Golfers react to every choice you make, just like the 2002 original.

Multiplayer

Build one course together. The server runs the simulation; roles decide who can build and spend.

No original files needed

Ships with a free asset set. Own the original game? Convert its art and sound into an asset pack.

Gameplay addons

New buildings, golfer types, events and rule changes, with a vanilla mode that turns them all off.

Modern UI

Clean panels over the course, readable reports and a build drawer with prices at a glance.

Standalone later

The same code is written to run as a standalone LÖVE game for Windows and Linux, updated from GitHub.

Asset packs

All graphics and sound come from packs. The server admin picks the active pack, and anything a pack leaves out falls back to the free set.

Default

Free

OpenSGolf's own art and sound, made without any original files. Ships with the gamemode.

Your own copy

Original

A converter app turns your own SimGolf install into a pack you add to your server. Never uploaded to the Workshop.

Workshop

Community

Anyone can make a pack, from a few new trees to a full new look. Partial packs work.

Built to be modded

Addons talk to the game through one event bus and a set of registries, so the same addon works in Garry's Mod and the standalone game.

  • Change rule tables: prices, golfer stats, terrain costs
  • Register new buildings, staff, golfer types, events and scenarios
  • Hook shots, moods, money and tournaments to add mechanics
  • Saves survive missing addons; vanilla mode is one switch
-- Planned addon API (Phase 4)
SimGolf.Data.Objects.bench.price = 50

SimGolf.RegisterObject("fountain_big", {
  name = "Grand fountain",
  price = 12000,
  footprint = { 3, 3 },
})

SimGolf.Hook.Add("ShotResult", "windy_days",
  function(golfer, shot)
    if SimGolf.Weather.wind > 20 then
      shot.accuracy = shot.accuracy * 0.8
    end
  end)
